# Простая программа управления задачами

Учебное задание на базовые конструкции Java.

## Цель

Создать программу для управления задачами, используя только базовые конструкции языка Java (массивы и циклы).

## Описание задания

1. Создать массив для хранения задач (задача — строка, которая отражает её название).
2. Реализовать функции для добавления, удаления, поиска и вывода задач.
3. Создать простой текстовый интерфейс для взаимодействия с пользователем.

## Требования

| № | Требование |
|---|---|
| 1 | Написать метод для добавления новой задачи |
| 2 | Написать метод для удаления задачи по её номеру |
| 3 | Написать метод для поиска задач по названию или идентификатору |
| 4 | Написать метод для обновления/изменения задачи по идентификатору |
| 5 | Написать метод для вывода всех задач |
| 6 | Методы должны вызываться соответствующими командами из консоли |

## Рекомендации

1. Начать с создания массива для хранения задач.
2. Реализовать методы для работы с массивом.
3. Создать цикл для интерактивного взаимодействия с пользователем.
4. Учесть, что хранилище задач (массив) может изменяться в размерах с ростом количества задач.
